# travel-agency
Проект тур-агентства: управление турами, клиентами и бронированиями
## Описание проекта
Веб-приложение для тур-агентства. Позволяет вести каталог туров,
управлять клиентами и оформлять бронирования. Backend — Node.js (Express + Sequelize),
база данных — PostgreSQL. Всё разворачивается в Docker.
